1, 给项目增加连通数据库的功能
        数据流：
        读配置 → 校验 → 【读数据】→ 跑检查 → 打印/导出
                            ↑
                    只有这一步和数据源耦合

    - 现在：`pd.read_csv(...)` 读 CSV
    - 以后：`pd.read_sql(...)` 读数据库

    读进来后都是 DataFrame，所以 run_checks、render、reporter 一行都不用改**—— 这就是当初强调 "DataFrame 是统一中间格式" 的回报

2， 连接数据库主要使用SQLAlchemy（**用一套接口连各种数据库**（SQLite/MySQL/PostgreSQL/Oracle/ 达梦，支持pandas）

        from sqlalchemy import create_engine
        engine = create_engine("sqlite:///demo.db")      # 连接串
        df = pd.read_sql_table("TableA", engine)        # 读整张表

        数据流：cli 是总指挥，data_loader 是其中一环
            1. load_rules [config_loader.py] → rules（字典）
            2. validate_rules [validator.py]
            3. load_dataframe [data_loader.py] → df（DataFrame）
            上游：CSV 文件或数据库　下游：df 交给第 4 步
            4. run_checks(df, 规则) [checker.py] → results（结果列表）
            5. render_results → 打印屏幕
            6. export_report → 写报告文件

        之前加载数据是写在cli的main里面，现在单独拿出来了。 `core/data_loader.py`（新）统一数据加载：CSV / 数据库都读成 DataFrame
